# Release Process

This project uses [GoReleaser](https://goreleaser.com/) and GitHub Actions to automate the release and distribution of the `gotenv` CLI.

## How to create a new release

When you are ready to publish a new version of `gotenv`, follow these steps:

1. **Commit your changes**
   Make sure that you commit and push all changes to the `main` branch.

2. **Tag the release**
   Create a new Git tag using semantic versioning (e.g., `v1.0.0`). The `v` prefix is required by the workflow.
   ```bash
   git tag v1.0.0
   ```

3. **Push the tag**
   Push the tag to GitHub. This will trigger the GitHub Actions release workflow.
   ```bash
   git push origin v1.0.0
   ```
   *(Alternatively, use `git push --tags` to push all local tags).*

## What happens automatically?

Once the tag is pushed to GitHub, the `.github/workflows/release.yml` GitHub Action starts automatically. The workflow uses GoReleaser to:

1. Build the binary for multiple operating systems (macOS, Linux, Windows) and architectures (amd64, arm64).
2. Create a new GitHub Release on the repository with autogenerated release notes.
3. Upload the compiled binaries (as `.tar.gz` or `.zip` archives) and a `checksums.txt` file to the release.
4. **(Optional)** Automatically update the Homebrew formula in your custom tap repository.

## Homebrew Tap Setup (One-Time Configuration)

To push the Homebrew formula to a tap repository, complete this one-time setup:

1. Create a public repository on GitHub named `homebrew-tap` under your account.
2. Generate a [GitHub Personal Access Token (PAT)](https://github.com/settings/tokens) with `repo` scope.
3. In this `gotenv` repository, navigate to **Settings > Secrets and variables > Actions** and create a new repository secret:
   - **Name:** `TAP_GITHUB_TOKEN`
   - **Secret:** *(Paste your PAT here)*
4. In `.goreleaser.yaml`, uncomment the `token` line under the `brews` section:
   ```yaml
   brews:
     - repository:
         owner: adampatterson
         name: homebrew-tap
         token: "{{ .Env.TAP_GITHUB_TOKEN }}" # <-- Uncommented
   ```
5. In `.github/workflows/release.yml`, uncomment the environment variable under the GoReleaser step:
   ```yaml
         env:
           GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
           TAP_GITHUB_TOKEN: ${{ secrets.TAP_GITHUB_TOKEN }} # <-- Uncommented
   ```

With this configured, every new tag pushed will automatically update your Homebrew tap, allowing users to install the latest version via `brew install adampatterson/tap/gotenv`.
